# Core Ascendant

This is a small incremental game built using React, Typescript, and Vite. The game is designed to be played in a web browser. The player accumulates energy which is used to unlock units, buildings, and spells, all which help the player earn even more energy. The objective of the game is to expand from planet to planet, establishing a galactic hivemind and ensuring the survival of your unique species.
